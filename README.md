# Twilightsaurus

Games, modding, MUD clients, and the tools around them.

My game-related development is spread across this account and two separate GitHub organizations.

## Find the projects

- [**i-mud organization**](https://github.com/i-mud) - MUD-related projects, including [Imp](https://github.com/i-mud/imp), a desktop companion for MUDs with live character status, alerts, and configurable actions.
- [**HeimForge organization**](https://github.com/heimforge-dev) - Valheim modding tools, including [HeimForge](https://github.com/heimforge-dev/heimforge), a generator for standalone Valheim mod-suite repositories.

## Cities: Skylines mods

I created and worked on a range of *Cities: Skylines* mods. The repositories now live on this gaming account.

- [**ForestBrush**](https://github.com/twilightsaurus/ForestBrush) - create brushes from tree assets.
- [**ThemeMixer**](https://github.com/twilightsaurus/ThemeMixer) - mix elements from different map themes.
- [**Painter**](https://github.com/twilightsaurus/Painter) - change colors of individual buildings.
- [**CustomizeIt**](https://github.com/twilightsaurus/CustomizeIt) - customize building properties in-game.
- [**BuildingAnarchy**](https://github.com/twilightsaurus/BuildingAnarchy), [**UniqueInstances**](https://github.com/twilightsaurus/UniqueInstances), and other original mods and modified forks are available in [my repositories](https://github.com/twilightsaurus?tab=repositories).
